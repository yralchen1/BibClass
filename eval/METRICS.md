## 1. Atomized keyword-quality metric (the latest)

**Atomization** — every keyword `species: code: type` is split into atomic units
`(element-ion, code, type)`:
- Element ranges expand: `Cr-Fe I` → Cr I, Mn I, Fe I.
- Charge ranges expand: `W XLV-XLVIII` → W XLV…XLVIII; `Al XII,XIII` → Al XII, Al XIII.
- Isoelectronic sequences kept whole: `Ar-U Be-like` = **one** unit (not expanded).
- Isotopes collapse to base element-ion: `85Rb I` → `Rb I` (base↔isotope match either way).
- One keyword line with N ions × M (well, 1) code → N units.

**Per gold unit:** exact `(ion+code+type)` = **1.0** · `ion+code` match but type differs = **0.5** · else **0**.
**Extra** = an AI unit whose `(ion, code)` is not in gold.

**Two paper scores:**
- **Penalize-extras:** `max(0, (credit − extras) / gold_units)`
- **No-penalty (recall):** `credit / gold_units` (extras ignored)
- **Empty-gold paper** (gold has no keywords): 100% if AI also empty, else 0% (both variants).

### Run B results — paper aggregation × both scores
| Weighting of papers | Penalize-extras | No-penalty (recall) |
|---|---|---|
| Unweighted (macro, each paper equal) | **48.0%** | **78.1%** |
| Gold-unit weighted | 40.5% | 63.8% |
| AI-unit weighted | 40.1% | 74.2% |
| Union (gold ∪ AI) weighted | 32.3% | 60.7% |
| Max(gold, AI) weighted | 34.5% | 63.3% |

*Micro pooled (Σcredit − Σextras)/Σgold, no per-paper clamp:* **22.2%** penalized · **63.8%** recall.
(Differs from gold-weighted penalized because micro doesn't clamp negative papers at 0.)

### Run B — count headlines
| Metric | Value |
|---|---|
| Perfect papers, penalize-extras (100%) | 24 / 95 |
| Perfect papers, no-penalty/recall (100%) | 57 / 95 |
| Empty-gold correct (AI emits nothing) | 7 / 9 |

**Reading:** recall is strong (~64–78%); precision is the wound (extras roughly halve every
penalized number). All weighted figures fall below the unweighted macro → the model is
**weaker on high-keyword-count papers** (wide ranges = more places to over-extend/over-assign).

## 1b. Decomposed Precision/Recall/F1 (recommended metric — `keyword_prf.py`)

Standard, bounded [0,1], balanced, and **diagnostic**: computed at three granularity levels
so the drop localizes where quality is lost. Atomization identical to §1. (95 papers.)

| Level | macro P | macro R | **macro F1** | micro P | micro R | **micro F1** |
|---|---|---|---|---|---|---|
| element-ion (species only) | 85.1% | 86.8% | **84.6%** | 77.4% | 59.3% | 67.1% |
| + code | 65.6% | 79.0% | **69.5%** | 59.0% | 64.0% | 61.4% |
| + type (full) | 64.4% | 77.8% | **68.2%** | 58.3% | 63.6% | 60.8% |

**Diagnosis (the key result):**
- **Species ≈ 85% F1** — the model finds the right element-ions well.
- **Adding code drops F1 by ~15 pts** — subject-code assignment (TE/ND/QF/AT over-assignment) is the bottleneck.
- **Adding type drops only ~1 pt** — method type E/T/O is essentially solved.
- Precision < recall at every level → the wound is **over-assignment**, not omission.

Why this is preferred over §1's `(credit−extras)/gold`: it is bounded, can't go negative,
isn't dominated by a few wide-range papers, and pinpoints the failing axis (species/code/type).

## 3. Worked example — paper 24084 (Hall), end-to-end

Gold (2 keyword lines) and AI both atomize to **42 units**.

```
Gold species: H I; C I; O I; Na-S I; K-Fe I; Ca II; Ni I; Zn I; Cs I   (× CL, W)
AI   species: H I; C I; O I; Na-Si I; S I; K-Fe I; Ni I; Zn I; Zr I; Cs I; Ca II   (× CL, W)
```
AI slips: range `Na-Si I; S I` skips **P**; adds **Zr**.

| Outcome | Count | Units |
|---|---|---|
| Exact (1.0) | 40 | shared ions × CL, W |
| Partial type-only (0.5) | 0 | — |
| Missed (0) | 2 | `P I: CL`, `P I: W` |
| Extra (−1) | 2 | `Zr I: CL`, `Zr I: W` |

```
credit = 40·1.0 + 0·0.5 = 40
Penalize-extras = max(0,(40 − 2)/42) = 90.5%
No-penalty      = 40/42              = 95.2%
```
Note: the strict paper-level scorer counts 24084 as a **zero-match** (raw strings differ), but
atomized it is **90–95% correct** — the atomized metric is far more faithful to output quality.
