     What Went Wrong in Each Version

     v1 — baseline

     QF/IP/ND)

     v2 — added rules + warnings + checklist (296 lines)

     - More conservative → cut SOME extras (-17) but also cut real matches (-12)
     - Net: perfect+no-extras rate UNCHANGED (19→19)

     (base drop), AP-10 (TA)
     - Some rules landed: dash preservation, list-vs-range, AT/TE independence
     (partial)
     - Lesson: long prompt → key rules buried; "be more conservative" is too
     vague — AI drops both noise AND signal

     v3 — anti-pattern bank + EVIDENCE_AUDIT (203 lines)

     - Catastrophic regression: strict 62%→25%, perfect 19→6

      explanations, no markdown") → AI inferred format was negotiable → invented
      combined-code/type formats:

       - H I: SE: E, T, O (three method types one line)

     Root-Cause Synthesis

     1. Format contract is fragile. Any new output section (EVIDENCE_AUDIT)
     makes AI treat format as flexible. Original v1 spec ("output ONLY the
     keywords fields ... no explanations, no markdown") must be preserved
     verbatim.
     2. Anti-patterns help with mechanical rules, fail at semantic ones.
       - Mechanical rules that landed: dash preservation, list-vs-range,
     hydrogen mass-1 collapse
       - Semantic rules that did NOT land: TA vs CL distinction, range bound
     correctness, base form retention
       - AI does pattern matching, not reasoning
     3. Conservatism without precision = lost signal. v2's "be more
     conservative" cut matches AND extras at same rate. Net zero gain. Need
     targeted conservatism, not blanket.
     4. Some "AI failures" are actually arguable. 24109 Kologrivov: paper Table
     III is "Interpretation of the sulfur spectra" — TA vs CL is genuinely
     ambiguous. AI may be right and reference may be questionable. Can't get to
     100% just from prompt engineering.
     5. Long prompts don't work for Gemini Flash. Model prioritizes recency and
     salience. Rules in middle of 270-line prompt are dropped. Few-shot examples
      + short, focused rules work better.
     6. Self-critique CAN work but requires care. v3's evidence audit produced
     useful reasoning when format wasn't broken. Need to keep the reasoning
     benefit without breaking the output contract.

     User-Locked Constraints (from clarification round)

     1. Metric = STRICT perfect+no-extras (base-form retention is hard
     requirement, not lenient).
     2. Target = match the original reference, even if AI's alternative
     interpretation may be defensible. Reference is authoritative.
     3. Pipeline = prompt-alone must produce clean output. NO post-processing
     validator. Format discipline must live entirely in the prompt.
     4. Scope = EL keywords ONLY. The prompt must NOT mention keywords_tp or
     keywords_lb at all (those have separate prompts run separately). Output is
     just keywords_el={...}.
     5. Novelty filter (CORE rule) = keywords are assigned ONLY for data that
     the paper genuinely presents as a NEW result. Do NOT assign keywords for:
       - Values cited from prior literature and used as inputs (e.g., NIST
     levels used to fit a new model)
       - Values reproduced for comparison only (e.g., a table column showing
     "previous values")
       - Routine recomputations of already-known quantities
       - Theoretical constants or ionization energies pulled from databases for
     context

      says "we measured X" or "we calculated X" → assign. If "we used X from Ref
      [n]" or "X is taken from [database]" → DO NOT assign.
